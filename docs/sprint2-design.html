Sidebar Structure

Anatomy, states, and behavior of the persistent left sidebar

Anatomy (Expanded · 240px)

Zone 1 — Brand Header
Product logo mark + wordmark. Workspace switcher dropdown below.


Zone 2 — Search
⌘K command palette trigger. Placeholder: "Search modules…". Never a real input — always fires the palette.


Zone 3 — Favorites
User-pinned modules. Right-click any nav item to pin. Max 5 favorites. Drag to reorder. Collapsible.


Zone 4 — Primary Nav
4 groups (OVERVIEW / CREATE / MANAGE / SYSTEM). Each group has a 10px uppercase label, 600 weight, muted color. Nav items: icon (20px) + label + optional badge count.


Zone 5 — Footer
Notification bell with unread count. Help & docs link. User avatar + name + plan tier. Upgrade CTA if on free plan.

States & Behaviors

Expanded → Collapsed
240px → 64px. Toggle button on sidebar edge. Icon-only view. Group labels hidden. Tooltips appear on hover (right side, 200ms delay).


Active Item
3px left border in primary blue. Background: blue-dim tint. Icon and label take primary color.


Hover
Background: raised tint. No border change. 80ms transition.


Badge
Right-aligned pill. Blue for counts. Yellow for "new". Red for alerts. Hidden at count = 0.


Nested Sub-items
Expandable via chevron. Sub-items appear 8px indented under parent. Parent label becomes "section header". Sub-items are lighter weight.


Keyboard
Tab to navigate. Enter to select. [ to collapse. ] to expand. / to open command palette.

Right Panel Structure

Dynamic settings panel — stays visible, changes per active module

Panel Shell (Always Present)

Header: Module icon + "Settings" label + [←] collapse button. 56px height. Sticky.
Body: Scrollable section stack. Each section is a collapsible accordion (chevron right, expands/collapses with 250ms ease).
Footer: Sticky to panel bottom. Contains the primary action button (Generate / Analyze / Process) + token/time estimate.

ModulePanel Sections (in order)
Brand Checker AI Model · Check Mode (Full / Quick / Logo Only) · Brand Guideline Version · Score Weights · Report Language · Export Format → [▶ Analyze]
Banner Generator AI Model · Prompt (textarea) · Negative Prompt · Canvas Size (preset dropdown + custom) · Brand Mode toggle · Style Presets · Variations count (1–4) · Export Format → [▶ Generate]
Image Generator AI Model · Prompt (textarea) · Negative Prompt · Image Size · Aspect Ratio (grid picker) · Quality slider · Creativity slider · Style Presets · Seed (input + randomize) · Reference Image (upload optional) → [▶ Generate]
Video Generator AI Model · Prompt (textarea) · Duration (3s/5s/10s/15s) · Frame Rate · Style Presets · Audio toggle · Resolution · Export Format → [▶ Generate]
Prompt Studio Mode (Create/Optimize/Translate/Analyze) · Input Language · Output Language · Tone · Template Presets · Advanced Options → [▶ Process]
Dashboard / Library / History / Team No right panel. Full width given to workspace. Panel collapses automatically.

Panel Behavior Notes

• Sections collapse individually. User preference is remembered per module.
• Every control has a (?) tooltip with one-line explanation on hover.
• "Advanced" accordion at the bottom of every module hides less-used options.
• Generate button shows estimated time: "~3.2s · 4 images" and is disabled during generation.
• Panel width is draggable: min 240px, max 420px, default 320px.

Responsive Strategy

How the 3-column layout adapts across devices without sacrificing function

BreakpointSidebarMain WorkspaceRight PanelKey Differences
≥ 1280px 240px expanded Full layout 320px always visible Nominal experience
1024–1279px 64px icon-only Full layout 280px always visible Sidebar tooltips active
900–1023px 64px icon-only Full layout Hidden; toggle button at workspace edge Panel overlays workspace, dims bg

Content Adaptations (Mobile)

Radar chart: Replaced with vertical score bar list — more readable at small widths.

Image grid: 4-col → 2-col on tablet → 1-col on mobile.

Banner canvas: Preview only; editing deferred to desktop.

Tables: Each row expands into a card on mobile. Overflow-x: auto on all data tables.

History timeline: Condensed card, less metadata visible, tap to expand.

Touch & Pointer Targets

Minimum tap target: 44×44px (WCAG 2.5.5 AAA).

Bottom tab bar: 60px height, icons 28px, spacing ≥ 12px between targets.

Slider controls: Track height increases from 4px to 8px on touch devices.

Nav items: 44px height minimum on all breakpoints.

Hover-only interactions (tooltips, hover previews) each have a tap-to-toggle fallback.

Interaction Design

Timing, easing, states, and micro-interaction specifications

All transitions respect prefers-reduced-motion: reduce — durations drop to 1ms when active.

Sidebar collapse
Width: 240px → 64px. 250ms ease-in-out. Label opacity: 1 → 0 at first 80ms. Icon stays pinned to left edge. Tooltips appear 200ms after hover on collapsed state.
Module switch
Workspace content: opacity 0→1, translateY 6px→0, 150ms ease-out. Right panel content re-renders instantly then fades in. No full-page transition.
Right panel open
Width: 0 → 320px. 200ms ease-in-out. Content fades in after panel is 60% open. On mobile: slides up from bottom 280ms cubic-bezier(.32,0,.67,0).
Generate button
Click → scale(0.97) 80ms. State changes to "Generating…" with spinner. Button disabled. Progress estimate updates in label. On complete: brief scale(1.02) pulse then normalize.
Image grid reveal
Generated images stagger in: each image opacity 0→1, scale 0.96→1, 200ms ease-out, offset by 60ms × index. Max 4 staggered — remaining appear together.
Upload drop zone
Drag-over: border color → primary, background → blue-dim, scale(1.01) 100ms. Drop: spinner overlay on preview 200ms. Invalid file: border → red, shake animation 400ms.
Card hover
Box-shadow elevation: sm → md. 100ms ease. No scale. Asset grid cards: overlay buttons appear at opacity 0→1, 120ms on hover.
Accordion section
Chevron rotates 0° → 180°. Content height: max-height 0 → auto via 250ms ease-in-out. Use measured pixel height, not `auto`, for smooth animation.
Toast notification
Slides up from bottom-right: translateY(16px)→0, opacity 0→1, 300ms ease-out. Auto-dismisses after 4s. Success: green left border. Error: red. Info: blue.
Command palette
Overlay: opacity 0→1 150ms. Modal: scale(0.97)→1, opacity 0→1, 200ms ease-out. Results filter in real-time as user types, no debounce delay.

UX Recommendations

Opinionated decisions to reduce friction, increase delight, and serve power users

  • 1
    Command Palette as primary navigation for power users
    ⌘K opens a global palette: search modules, jump to recent files, trigger any action, see keyboard shortcuts. This is the single most impactful feature for reducing click depth for experienced users. Model it on Linear's command palette.
  • 2
    Auto-save everything as drafts
    Every prompt typed, every upload, every generation is automatically persisted in History. Users never need to manually save. "Draft" badge appears on workspace tab if unsaved changes exist. Eliminates anxiety about losing work.
  • 3
    Progressive disclosure in the right panel
    Show 3–4 most-used controls by default. Everything else lives inside an "Advanced Options" accordion, collapsed by default. This keeps the panel scannable for new users while giving experts full control.
  • 4
    Rich empty states with specific quick-start actions
    Every module's empty state should show 3 suggested starting actions (not just an illustration). For Image Generator: "Try: ZaloPay user on phone" · "Try: Tết campaign banner" · "Try: product on white background". Remove all friction from first use.
  • 5
    Real-time token and time estimate before generating
    The Generate button label should show "~3.2s · 4 images" computed from current settings. Users understand what they're requesting before committing. Prevent surprise on slow generations.
  • 6
    Score delta on Brand Checker re-runs
    When a user re-checks an updated design, show the score change: "Logo +1.5 ↑ · Color −0.5 ↓". Makes iteration feel rewarding and shows which changes had impact.
  • 7
    Pin frequently used modules to Favorites
    Right-click (or long-press) any sidebar item to pin it to the Favorites section. Drag to reorder. Saves repetitive navigation for users who live in 1–2 modules daily.
  • 8
    Inline contextual help on every control
    Every right-panel setting has a (?) icon. Hover shows a tooltip explaining the setting in one plain sentence. No need to open documentation. Dramatically reduces support load for new users.
  • 9
    Batch operations in Asset Library and History
    Multi-select with Shift+click or checkbox toggle. Batch download, delete, move to folder, or re-run analysis. Critical for team users managing large asset volumes.
  • 10
    Seed locking for reproducible generations
    In Image and Banner generators, show the seed used for each output. Let users lock a seed with one click to iterate on a composition while changing other params. Mirrors Midjourney's power-user workflow.

Future Expansion Strategy

How the architecture scales to 30+ modules without redesigning navigation

Module Registry Pattern

Each module is one config object in a registry:

{
  id: "image-gen",
  label: "Image Generator",
  icon: Sparkles,
  group: "CREATE",
  beta: false,
  workspace: ImageGeneratorView,
  rightPanel: ImageGenPanel,
  subNav: ["Generate","Library","Upscale"]
}

Adding a new module = adding one object. Zero structural changes to nav, layout, or routing.

Navigation Scaling

10 modules (current): Full labels always visible. No search needed.

15–20 modules: Groups become collapsible. Search trigger gets more prominent.

20–30 modules: New sub-groups appear inside CREATE/MANAGE. Command palette becomes the primary discovery surface. Sidebar defaults to Favorites + Recent only.

30+ modules: Module catalog page replaces exhaustive sidebar listing. Sidebar shows only pinned + recent.

Feature Flag System

New modules ship with beta: true — shown with a "Beta" badge in the sidebar. Toggle per workspace in Settings. Allows gradual rollout without disrupting production users. When stable, flip flag to remove badge.

Right Panel Plugin Architecture

Each module registers its own right-panel sections. The panel shell never changes — it renders whatever sections the active module declares. New AI capabilities can add controls without touching the panel component.
